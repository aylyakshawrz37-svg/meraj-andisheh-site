# آموزشگاه معراج اندیشه — نسخه مستقل برای GitHub Pages

این نسخه فقط از `index.html` تشکیل شده و نیازی به npm، Node.js، build یا سرویس جانبی برای نمایش صفحه ندارد.

## نشانی رایگان GitHub Pages

پس از قرار گرفتن `index.html` در ریشه شاخه `main` مخزن `meraj-andisheh-site` و فعال کردن Pages از مسیر **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**، آدرس پروژه به شکل زیر خواهد بود:

`https://aylyakshawrz37-svg.github.io/meraj-andisheh-site/`

## دامنه اختصاصی academysmeraj.ir

GitHub دامنه اختصاصی را نمی‌فروشد؛ GitHub Pages یک زیردامنه رایگان `github.io` ارائه می‌کند و می‌تواند دامنه‌ای را که خودت مالک آن هستی هم متصل کند. برای دامنه `.ir`، بعداً باید `academysmeraj.ir` در Settings → Pages ثبت شود و رکوردهای DNS نزد شرکت مدیریت دامنه تنظیم شوند. تا آن زمان از آدرس رایگان `github.io` استفاده کن.

## بررسی محتوا پیش از استفاده واقعی

- فرم مشاوره در این نسخه نمایشی است و هیچ اطلاعاتی را ارسال یا ذخیره نمی‌کند؛ در خود صفحه این موضوع اعلام شده است.
- شماره تماس، نشانی، نام مدرسان، قیمت نهایی دوره‌ها و ادعاهای مربوط به مدرک یا مجوز عمداً به‌عنوان اطلاعات تأییدنشده نمایش داده نشده‌اند؛ پیش از انتشار عمومی این موارد را با اطلاعات واقعی تکمیل کن.
